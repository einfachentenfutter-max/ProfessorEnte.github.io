PROFESSORENTE PORTFOLIO
=======================

Starten:  index.html doppelklicken (Internet für die Schriftarten empfohlen).

Anpassen:
  js/data.js    Scripts, Rollen, Projekte, Lernfelder, Werkzeugkasten
                (neues Script: einen Block im Bereich "scripts" kopieren)
  js/config.js  Discord, E-Mail, GitHub, YouTube eintragen (leer = ausgeblendet)
  css/style.css Farben stehen ganz oben unter :root

Online stellen: den ganzen Ordner auf GitHub Pages, Netlify oder
deinen Webspace hochladen. Keine Installation nötig.
